# Processamento Digital de Imagens - Aula 02

Este repositório contém a resolução dos experimentos práticos propostos na disciplina de Processamento Digital de Imagens (PDI).

## 📂 Estrutura do Projeto

*   `script.ipynb`: Notebook Jupyter com a implementação dos 4 experimentos.
*   `image.png`: Imagem original utilizada como referência.
*   `imagem.csv`: Matriz de pixels em formato CSV para conversão em imagem.
*   `Aula 02 - Formação da Imagem.pdf`: Material teórico de apoio.

## 🚀 Experimentos Realizados

1.  **Escala de Cinza:** Leitura de imagem, conversão para tons de cinza e clareamento (+100 unidades).
2.  **Imagem Colorida:** Aplicação de brilho (+100 unidades) diretamente nos canais RGB.
3.  **Processamento em Lote:** Automação para processar todas as imagens de um diretório específico.
4.  **CSV para PNG:** Reconstrução de uma imagem digital a partir de dados numéricos em uma planilha.

## 🛠️ Requisitos

Para rodar o notebook localmente, instale as dependências necessárias:

```bash
pip install numpy matplotlib pillow
```

## 📖 Como Executar

1.  Abra o arquivo `script.ipynb` no **VS Code**, **Jupyter Notebook** ou **Google Colab**.
2.  Certifique-se de que os arquivos `image.png` e `imagem.csv` estão na mesma pasta que o notebook.
3.  Execute as células sequencialmente para visualizar os resultados e gerar as novas imagens.
